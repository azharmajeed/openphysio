New or returning runners do best mixing short run and walk intervals, then lengthening the run portions over several weeks. Run two to three days a week at an easy pace where you could hold a conversation. Add only one variable at a time: time, or frequency, or pace. Every fourth week, ease off. If a niggle appears, shorten the next run and watch how it settles before going on.
