## Scope of v0.1
Android app on Pixel 8a, one user, data on the phone plus a self-hosted server. Out: other users, iOS, store release, live pose coaching, basketball video.

## Architecture
- Phone: Gadgetbridge (pairs with the band instead of Mi Fitness) → Health Connect → OpenPhysio app (Expo) ↔ local SQLite (offline at gym/pool).
- Server (one Docker container, laptop for v0.1): Hono API (sync, scan import, coach tools, Strava upload, Learn feeds), AI adapter (keys live only here), SQLite + files (profile, logs, scans, demo clips).
- Outside services reached only through the server: trainer YouTube channels, GPU pod (demo generation), AI provider (hosted key or local), Strava (out only).

## Plan engine for Azhar's goals
- Run faster/longer: 3 runs/week (easy, intervals or tempo, long); long run grows under the spike guard.
- Swim more: 1–2 sessions (technique drills, then intervals).
- Jump higher: plyometrics 2×/week with capped foot contacts, lower-body strength, knee and tibialis work (Knees Over Toes style).
- Back for long sitting: rows, hinges, back extensions with bands/dumbbells; side plank and bird dog holds; desk breaks (Posture Lab).
- Healthy weight gain: 10+ hard sets per muscle per week (ACSM 2026); nutrition targets.
- Example week: Mon lower strength + plyos (home); Tue swim technique + back/core; Wed run intervals; Thu upper strength + back (gym); Fri mobility/knee work or rest; Sat long run; Sun easy swim + weekly check-in.

## Safety rules (packages/core)
- Injury filter: every plan, swap and coach answer reads the injury list; "avoid if" exercises for affected areas are excluded.
- Spike guard: no session's run distance, jump count or muscle volume more than 10% above the biggest in the last 30 days (Frandsen 2025, BJSM).
- Pain monitor: ≤5/10 during and settled by next morning = continue; higher or worsening = easier variant; sharp pain, swelling, giving way = stop and see a physio.
- Prevention warm-up in every session.

## Nutrition (packages/core)
- Protein 1.4–2.0 g/kg/day, ~0.25 g/kg (20–40 g) per meal every 3–4 h (ISSN, Jäger 2017).
- Calories 10–20% above maintenance; target 0.25–0.5% bodyweight gain/week; trained = low end.
- Adjust from the 2-week weight trend (app rule, grade C). Activity calories from the band added on training days.

## AI coach
Cloud LLM with tool calling behind the server adapter; read tools (profile, injuries, plan, logs, recovery), knowledge search with citations, write tools later (log sets, propose plan changes). Red-flag check runs before the model. Plan changes must pass the safety rules and the user's confirmation. Memory: profile + coach notes written after each chat.

## AI-generated exercise demos (workers/motion)
1. Catalogue entry → prompt (name, tempo, cues, key angles).
2. HY-Motion 1.0 → SMPL-H motion at 30 fps (community licence excludes EU, UK, South Korea; confirm distribution of generated clips is allowed).
3. Auto-check: joint angles from the motion run through the same JSON form rules; failures regenerate.
4. Azhar approves takes (reuse video-gen's take-review UI).
5. Render a neutral mannequin, front and side, short loops; keep the motion file.
6. Optional realistic pass with Wan2.2-Animate (check licence).
7. Fallback: film the exercise at home.
GPU batches need Azhar's approval. Trainer content stays embedded YouTube in the Learn tab.
