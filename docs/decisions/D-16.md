# D-16: UI kit, styling engine and dev loop for v0.2
Project and affected tasks: OpenPhysio v0.2 — UI0 and every UI task
Decision type: Technical
Why the decision is needed: TP-003 section 1 left the kit to a spike (UI0).
Evidence and current constraints (UI0 spike, 2026-11-18/19):
- Native libraries: Reanimated 4.7.1, Gesture Handler 3.3.0 and Worklets 0.13.0 now build on Windows. The fix was to point Gradle at the SDK's CMake 3.31.6 (`cmake.dir` in android/local.properties, written by `plugins/short-cxx.js`); its ninja 1.12.1 handles long paths, and Windows long paths are already enabled. The WSL and GitHub Actions fallbacks of D-22 were not needed. First clean x86_64 debug build: 22.5 min.
- Kit: React Native Reusables (Uniwind registry, MIT) on Uniwind 1.14 (MIT core) with Tailwind 4.3. Components are copied into `apps/mobile/src/components/ui` (from the registry source, not the CLI, which emitted NativeWind code for icon.tsx). Today was ported; it renders on the emulator through the dev client.
- Theme: `apps/mobile/global.css` holds light and dark variables (dark-first palette, one accent, `good`/`watch`/`stop` state colours). Navigation chrome reads the same variables through `useCSSVariable`. Following the system light/dark setting on Android needs `expo-system-ui` (added).
- Sheets: @gorhom/bottom-sheet 5.2.14 has had no release since 2026-05 and predates Gesture Handler 3. Expo Router's native `formSheet` presentation needs no extra dependency.
- Dev loop: `expo-dev-client` build + Metro. Edits reload in seconds; release APKs only for handing over a build.
Options with consequences: Reusables on Uniwind; NativeWind (v5 still preview); HeroUI Native.
Recommended option and rationale: Reusables on Uniwind: it works on SDK 58, the code lives in our repo, and it is the shadcn model that is easy to restyle.
What can continue independently: n/a
Decision owner: orchestrator (technical choice within approved TP-003; Azhar to be told, asked only if it changes the plan)
Answer and timestamp: Reusables on Uniwind; sheets use Expo Router `formSheet`, with @gorhom/bottom-sheet only if a screen needs more; dev client for daily work. — 2026-11-19
Scope/version to which the answer applies: v0.2 UI tasks (UI1a onward)
