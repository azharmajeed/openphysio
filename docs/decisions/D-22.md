# D-22: Android build path for v0.2 native libraries
Project and affected tasks: OpenPhysio v0.2 — UI0 and every mobile task
Decision type: Technical
Why the decision is needed: The UI kit needs Reanimated, Gesture Handler and Worklets, which M1 excluded because the Windows native build hits the 260-character path limit.
Evidence and current constraints: docs/tasks/M1.md; WSL 2 with Ubuntu is installed on the laptop (7 GB RAM, no Node, JDK or Android SDK yet).
Options with consequences: Fix the Windows build; build in WSL Ubuntu; build in GitHub Actions on Linux (free minutes on the private repo).
Recommended option and rationale: Try Windows in UI0 first; if it fails, build in WSL (local, free, Linux paths); GitHub Actions as the second fallback.
